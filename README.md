# ABI Sound Archive

Browse recovered artifacts and listen to their unique sounds through a responsive web player.

## [Open the ABI Sound Archive](https://wesleywmg2609.github.io/abi-sound-archive/)

## Features

- 31 artifacts with matching artwork
- Shared pickup and drop audio organized by sound group
- Search, category, and sound-group filters
- Play, pause, previous, next, and seek controls
- Responsive layout for desktop and mobile
- Built with Expo and React Native Web

## Run locally

```bash
npm install
npm run web
```

## Create a production build

```bash
npm run build:web
```

The production files are exported to `dist`. Pushes to `main` are deployed automatically through GitHub Actions.
